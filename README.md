# Guess It

Online multiplayer number-guessing game built with React/Vite + Node/Express/Socket.IO.

## Run
1. Install Node.js 20+.
2. Run `npm install`.
3. Run `npm run install:all`.
4. Run `npm run dev`.
5. Open the Vite URL.

Includes accounts, public 2-6 player rooms, private friend rooms, server-authoritative games, ordered number boards, player stats, cosmetic shop, language settings and one-use admin code support.
